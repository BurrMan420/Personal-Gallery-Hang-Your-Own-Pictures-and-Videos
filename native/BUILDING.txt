The mod's Papyrus scripts are in ../papyrus, or in the download under scripts/source (same licence).

BUILDING
1. Put CommonLibSSE-NG in external/CommonLibSSE:
     git clone https://github.com/alandtse/CommonLibVR external/CommonLibSSE
   (built against commit 8eaddedd1542290701ccb0e9e88b2af8b3cea597)
2. Visual Studio with the C++ workload, CMake, Ninja and vcpkg. build.bat expects Visual Studio's
   own copies; change the two paths at its top if yours are elsewhere.
3. Run build.bat. The plugin is written to build/PersonalGalleryNative.dll.
