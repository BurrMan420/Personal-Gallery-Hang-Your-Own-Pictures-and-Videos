# Personal Gallery - Hang Your Own Pictures and Videos

Source code of the Skyrim Special Edition mod **Personal Gallery**: hang your own pictures and
videos on the walls of Skyrim, in frames, on stands and as projections.

- `native/` - the SKSE plugin `PersonalGalleryNative.dll` (C++23). See `native/BUILDING.txt`.
- `papyrus/` - the mod's Papyrus scripts.
- `Mod-Readme.txt` - the readme shipped with the mod.
